# VectorAI

This is what you hope it is, a next level AI ATC addon for GeoFS. I have worked together with Claude and SayintentionsAI on this projecct and this is the first release.

# What are the requirements for using this addon?

- Tampermonkey or another script manager installed
- An OpenAI account, you can create one at https://platform.openai.com/home
- API credits, these can be bought on the same website
- An API key, you paste it into the UI of VectorAI and it fires up
- A [ChartFox](https://chartfox.org) account is not neccesary, but highly recommended, since VectorAI mostly uses their charts


# How does it work?

VectorAI uses an API key from OpenAI voice models, which makes sure you get the most realistic air traffic control possible.
You generate an API key on https://platform.openai.com/home and buy credits for it.
These credits are limited, because these models are really powerful and can't be free to use. 
Some people might say this shouldn't be paid (and I agree), but that is the only way you can have the most realistic experience possible.

One cycle (arrival or departure) with full ATC coverage is between €1,- and €1,60.

# Current support

VectorAI currently supports EHAM (AMS) and LFPG (CDG) with full coverage. I am working on EGLL (LHR) and EDDF (FRA) for the next major update. Current version is V1.


Check out this PDF for instructions on both airports. [EHAM-LFPG-Local-Procedures.pdf](https://github.com/user-attachments/files/35232869/EHAM-LFPG-Local-Procedures.pdf)
